# Support Operations Question Bank

An existing multiple-choice bank, written outside Knowzy, used to exercise the
import path. Two questions in prose form.

Which cancellation reason sends no status message to the customer?
A. LAB SYSTEM SETUP AND TEST
B. LMS PATIENT REQUEST
C. A blank cancellation reason
D. Any reason chosen by the handler
Answer: A
Explanation: The SOP records that this reason suppresses the customer status message, and a blank reason must never be selected.

How many days before expiry should an SSL certificate be renewed when no official threshold is defined?
A. Seven days
B. Thirty days
C. Sixty days
D. Ninety days
Answer: C
Explanation: Where no official threshold exists the procedure directs L2 to use a practical operational threshold of sixty days and to align it with management.
